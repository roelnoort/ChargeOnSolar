# ChargeOnSolar

## Agent skills

### Issue tracker

Issues are tracked in GitHub Issues on roelnoort/ChargeOnSolar (via the `gh` CLI). See `docs/agents/issue-tracker.md`.

### Triage labels

Default labels: `needs-triage`, `needs-info`, `ready-for-agent`, `ready-for-human`, `wontfix`. See `docs/agents/triage-labels.md`.

### Software factory

Label-driven agents (`agent:explore`, `agent:implement`, `agent:review`, `agent:implement-spec`) run in GitHub Actions. See `docs/agents/factory.md`.

### Domain docs

Single-context: one root `GLOSSARY.md` and `docs/adr/`. See `docs/agents/domain.md`.
